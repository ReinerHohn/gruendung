# Gründungs-Checkliste

## Phase 1 — Vorbereitung (Monate vor Gründung)

### Idee & Markt
- [ ] Geschäftsidee schriftlich ausformuliert
- [ ] Zielgruppe definiert
- [ ] Wettbewerber analysiert
- [ ] Alleinstellungsmerkmal (USP) herausgearbeitet
- [ ] Erste Kundengespräche geführt (ggf. Letters of Intent)

### Rechtsform wählen → [Vergleich](rechtsformen/vergleich.md)
- [ ] Haftungsrisiko bewertet
- [ ] Stammkapital-Bedarf geprüft
- [ ] Steuerliche Konsequenzen verglichen
- [ ] Rechtsform entschieden: **_______________**

### Businessplan → [Vorlage](businessplan/vorlage.md)
- [ ] Executive Summary
- [ ] Produkt/Dienstleistung beschrieben
- [ ] Marktanalyse
- [ ] Marketing- & Vertriebsstrategie
- [ ] Unternehmensstruktur
- [ ] Finanzplanung (3 Jahre)
- [ ] Risikoanalyse

### Finanzplanung → [Templates](finanzen/)
- [ ] Kapitalbedarf berechnet
- [ ] Eigenkapital vorhanden / geklärt
- [ ] Fremdfinanzierung geprüft (KfW, Hausbank, Investoren)
- [ ] Liquiditätsplan für 12 Monate erstellt
- [ ] Preiskalkulation fertig

---

## Phase 2 — Gründungsakt

### Für UG / GmbH (Notarpflicht)
- [ ] Firma (Name) geprüft → [IHK Namenscheck](https://www.ihk.de)
- [ ] Satzung / Gesellschaftsvertrag erstellt → [Muster](dokumente/satzung_muster.md)
- [ ] Notartermin vereinbart
- [ ] Stammkapital auf Konto eingezahlt (bei GmbH: mind. 12.500 €, bei UG: mind. 1 €)
- [ ] Bankbestätigung über Einzahlung besorgt
- [ ] Notartermin wahrgenommen, Gründungsurkunde erhalten
- [ ] Handelsregistereintrag beantragt (macht Notar)
- [ ] Handelsregisternummer erhalten (HRB xxxxxx)

### Für GbR / Einzelunternehmen (kein Notar nötig)
- [ ] Gesellschaftsvertrag (GbR) schriftlich aufgesetzt
- [ ] Firma-/Unternehmensname festgelegt

---

## Phase 3 — Behörden & Anmeldungen → [Details](behoerden/)

### Gewerbeamt
- [ ] Gewerbeanmeldung eingereicht (Formular, ca. 10–65 €)
  - Benötigt: Personalausweis, ggf. HR-Auszug, ggf. Konzession
- [ ] Gewerbeschein erhalten

### Finanzamt
- [ ] Fragebogen zur steuerlichen Erfassung ausgefüllt (online via ELSTER)
  - → Steuernummer und ggf. USt-IdNr. erhalten
- [ ] Kleinunternehmerregelung (§ 19 UStG) geprüft: ja / nein
- [ ] Voranmeldungszeitraum festgelegt (monatlich / vierteljährlich)

### IHK / HWK
- [ ] Pflichtmitgliedschaft IHK oder HWK geprüft
  - Handwerker: HWK, alle anderen: IHK (automatisch bei Gewerbeanmeldung)

### Sozialversicherung (Solo-Gründer)
- [ ] Krankenversicherung geregelt (GKV freiwillig oder PKV)
- [ ] Rentenversicherungspflicht geprüft (bestimmte Berufe: Pflicht!)
- [ ] Berufsgenossenschaft (BG) gemeldet

---

## Phase 4 — Operativer Start

### Banking & Buchhaltung
- [ ] Geschäftskonto eröffnet (getrennt von Privat — auch bei Einzelunternehmen empfohlen)
- [ ] Buchhaltungssoftware gewählt (DATEV / Lexoffice / Sevdesk / etc.)
- [ ] Steuerberater beauftragt (oder Selbst-Buch geregelt)
- [ ] Kassenbuchführung / doppelte Buchführung (ab GmbH Pflicht)

### Rechtliches
- [ ] AGB erstellt (falls B2C)
- [ ] Impressum & Datenschutzerklärung für Website
- [ ] Musterverträge (Kunden, Lieferanten, Freelancer) → [Dokumente](dokumente/)
- [ ] Domain / Marke gesichert (DPMA-Markenrecherche)

### Versicherungen → [Übersicht](versicherungen/uebersicht.md)
- [ ] Betriebshaftpflicht
- [ ] Berufsunfähigkeit (persönlich)
- [ ] Weitere je nach Branche

### Go-Live
- [ ] Website online
- [ ] Erster Kunde / erster Auftrag
- [ ] Rechnung gestellt (korrekte Pflichtangaben!)

## Wichtige Fristen

| Frist | Was |
|---|---|
| Sofort nach Gründung | Gewerbeanmeldung (i.d.R. innerhalb 2 Wochen) |
| 1 Monat nach Aufnahme | Fragebogen Finanzamt |
| Laufend | USt-Voranmeldung (10. des Folgemonats/-quartals) |
| Jährlich | Jahresabschluss / Steuererklärung |
| Bei GmbH/UG: jährlich | Offenlegung Jahresabschluss im Bundesanzeiger |
